## 🤝 Contribute

Want to add a game? Awesome! Here's how:

1. Fork this repository
2. Edit `README.md` — add your game to the right category, using the table format:

```markdown
| **[Game Name](https://example.com/)** | One-line description of what the game is. | [▶ Play](https://example.com/) |
```

3. Submit a Pull Request

### Guidelines

- ✅ Game must be **free** and **playable in-browser** (no downloads)
- ✅ Use the game's official URL (no affiliate/tracking links)
- ✅ Keep descriptions concise (1 sentence)
- ❌ No paid games, no malware, no 18+ content
